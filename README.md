# Boutique Esencia

Boutique Esencia es una aplicación web desarrollada con React que presenta un catálogo de perfumes y permite navegar entre distintas secciones del sitio.

Este proyecto corresponde a la migración a React de un sitio realizado previamente con HTML y CSS.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS
- React Router DOM
- Font Awesome

## Funcionalidades

- Navegación entre páginas con React Router.
- Catálogo de productos mediante componentes reutilizables.
- Uso de props en las tarjetas de productos.
- Galería de imágenes.
- Formulario de contacto controlado con useState.
- Eventos del formulario mostrados en la consola.
- Botones para enviar y limpiar el formulario.
- Menú hamburguesa para dispositivos móviles.
- Diseño responsive para computadora, tablet y celular.

## Instalación

Para instalar las dependencias del proyecto:

```bash
npm install
```

## Ejecución

Para iniciar el proyecto en modo desarrollo:

```bash
npm run dev
```

Luego abrir en el navegador la dirección que indique Vite en la terminal.
